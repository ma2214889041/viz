从一次量子抖动到一张宇宙网

宇宙网不是被谁画出来的。它的种子是暴胀期间一个量子场不可避免的涨落，被暴胀拉出视界而冻结成经典的密度扰动，再被引力放大了四万倍。这一条因果链是现代宇宙学的主线剧情。

1980–82

暴胀与原初涨落谱

Guth 提出暴胀解决视界与平坦性问题；随后 Mukhanov–Chibisov、Hawking、Guth–Pi、Starobinsky、Bardeen–Steinhardt–Turner 等人算出：暴胀场的量子涨落会留下一个近乎标度不变的谱。

1970

Zel'dovich 近似

Zel'dovich 指出：一块物质沿三个主轴的坍缩速度不同，最短轴先塌，于是先压成「饼」。这就是宇宙网不是一团团而是网状的原因。

1986

「长城」与 BBKS

de Lapparent、Geller 与 Huchra 的红移巡天画出第一张明确的纤维与空洞图。同年 Bardeen–Bond–Kaiser–Szalay 给出至今仍在用的转移函数拟合公式 —— 本页用的就是它。

1992

COBE 测到 10⁻⁵

COBE 首次测到微波背景的温度各向异性，幅度约十万分之一。整张宇宙网的种子被直接看见了。

2005–

Millennium 及其后继

Millennium、IllustrisTNG、EAGLE、Uchuu 等数值模拟长出的网，与巡天看到的网在统计上一致。这是宇宙学最漂亮的成功之一。

2018 / 2024–

Planck 与 DESI

Planck 把谱指数测到 ns ≈ 0.965 —— 略小于 1，正是暴胀模型的预言。DESI 正在用数千万条星系红移把这张网量得更细。

这一页在算什么
粒子-网格（PM）N-body：把 32768 个粒子撒进周期盒子，每一步用 CIC 撒到网格上、FFT 解泊松方程、把力插回粒子、按 ln a 等步长做 kick–drift–kick。初条件是高斯随机场 + Zel'dovich 位移，功率谱取 P(k) ∝ knsT²(k)，T 用 BBKS 拟合式。

可以核对的原始文献
Bardeen, Bond, Kaiser, Szalay (1986) — 转移函数拟合式（本页 T(k) 的出处）
Zel'dovich (1970) — 各向异性坍缩与「饼」
Planck 2018 宇宙学参数（ns = 0.9649 ± 0.0042）
Springel 等 (2005) — Millennium 模拟

这一页没有算的
没有重子、没有气体、没有恒星形成、没有中微子、没有辐射时期。它是纯冷暗物质的引力演化 —— 宇宙网的骨架确实是这么长出来的，但真实星系长在骨架上还需要另一整套物理。分辨率也只有 32³：能看出纤维和空洞，看不出单个星系晕。
