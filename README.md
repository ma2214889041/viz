# VIZ

一个关于数学与物理的交互式可视化博客。

根目录是博客首页，每个子目录是一篇可以独立阅读、操作和分享的可视化文章。

每篇文章都是**一个自包含的 HTML 文件**：没有运行时依赖，没有 CDN。站点构建只负责验证文章、复制静态文件并生成文章清单、Sitemap 与 RSS。

## 文章

| | 文章 | 说明 |
|---|---|---|
| 数学 | [一根针](kakeya/) | 三维挂谷猜想。10 章分步讲解。 |
| 物理 × 数学 | [一盒气体](boltzmann/) | 玻尔兹曼方程、时间之箭与希尔伯特第六问题。7 章分步讲解。 |
| 首期合集 | [一根针与一盒气体](kakeya-boltzmann/) | 两篇作品的原始合集版本。 |

## 加一篇新文章

1. 建文件夹 `your-work/`，放入自包含的 `index.html`
2. 按现有格式增加 `work.json`
3. 在 `scripts/build.mjs` 的 `workDirs` 中登记目录
4. 在首页文章列表中增加对应入口
5. 使用明确的问题作为标题，并写清主题、预计阅读时间、可以操作什么、最终能理解什么

文章应遵循同一条叙事路径：提出问题 → 看见结构 → 动手实验 → 回到事实与来源。

## 本地预览

```bash
npm run build
npm run preview
```

然后打开 http://localhost:8000

## 部署

正式地址：<https://viz.gopromp.com>

正式环境使用 Cloudflare Workers Static Assets，配置文件为 `wrangler.jsonc`。运行 `npm run deploy` 会完成构建并更新正式站点。

同时保留 Cloudflare Pages 项目 `viz` 作为备用部署与预览地址；构建命令为 `npm run build`，输出目录为 `dist`。

## 关于内容的准确性

演示里出现的数值都是实时算出来的，不是写死的动画。做的时候用独立的 Node 脚本交叉验证过：

- 挂谷集的体积与 Perron 树递归的独立实现比对，相对误差 < 1e-5
- 12 个方向锥的覆盖率用 6 万个随机方向抽样验证：100%，且 12 个变换矩阵严格正交
- 硬球气体的能量守恒到 1e-8（机器精度）；速率分布与麦克斯韦–玻尔兹曼曲线的 L1 偏差落在 √N 散粒噪声量级内
- H 函数在时间反演后的回升幅度、盒维数随尺度的变化，都是实测数据
