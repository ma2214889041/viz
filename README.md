# VIZ

一个关于数学、物理、数据与系统的交互式可视化刊物。

这里不是只解释某两个数学问题的专题页。根目录是刊物首页，每个子目录是一篇可以独立阅读、操作和分享的可视化作品。

每个作品都是**一个自包含的 HTML 文件**：没有构建步骤，没有外部依赖，没有 CDN。双击就能开，也能直接扔到任何静态托管上。

## 作品

| | 作品 | 说明 |
|---|---|---|
| 数学 | [一根针](kakeya/) | 三维挂谷猜想。10 章分步讲解。 |
| 物理 × 数学 | [一盒气体](boltzmann/) | 玻尔兹曼方程、时间之箭与希尔伯特第六问题。7 章分步讲解。 |
| 首期合集 | [一根针与一盒气体](kakeya-boltzmann/) | 两篇作品的原始合集版本。 |

## 加一个新作品

1. 建文件夹 `your-work/`，放一个 `index.html` 进去
2. 在根目录 `index.html` 的「作品档案」中增加对应卡片
3. 使用明确的问题作为标题，并写清主题、预计阅读时间、可以操作什么、最终能理解什么

作品应遵循同一条叙事路径：提出问题 → 看见结构 → 动手实验 → 回到事实与来源。

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000

## 部署

纯静态站点，任何静态托管都行。Cloudflare Pages 连上这个仓库即可，构建命令留空、输出目录填 `/`。

## 关于内容的准确性

演示里出现的数值都是实时算出来的，不是写死的动画。做的时候用独立的 Node 脚本交叉验证过：

- 挂谷集的体积与 Perron 树递归的独立实现比对，相对误差 < 1e-5
- 12 个方向锥的覆盖率用 6 万个随机方向抽样验证：100%，且 12 个变换矩阵严格正交
- 硬球气体的能量守恒到 1e-8（机器精度）；速率分布与麦克斯韦–玻尔兹曼曲线的 L1 偏差落在 √N 散粒噪声量级内
- H 函数在时间反演后的回升幅度、盒维数随尺度的变化，都是实测数据
