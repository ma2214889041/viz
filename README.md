# VIZ

一个关于数学、科学与思想的交互式可视化博客。

根目录是博客首页，每个子目录是一篇可以独立阅读、操作和分享的可视化文章。

每篇文章的界面都是**一个自包含的 HTML 文件**：没有前端框架、没有 CDN。站点构建负责验证文章、复制静态文件并生成文章清单、Sitemap 与 RSS。需要真实共享状态的文章由同一域名下的 Cloudflare Worker 提供有限 API。

## 加一篇新文章

1. 建文件夹 `your-work/`，放入自包含的 `index.html`
2. 按现有格式增加 `work.json`
3. 在 `scripts/build.mjs` 的 `workDirs` 中登记目录
4. 在首页文章列表中增加对应入口
5. 使用明确的问题作为标题，并写清主题、预计阅读时间、可以操作什么、最终能理解什么

文章不套用固定叙事模板。先判断它需要哪一种认识动作，再从
[方法文章](methods/) 选择论证语言。每个互动至少要写清：读者做什么、模型改变什么、什么观测构成证据、哪个旧解释因此失效。

## 本地预览

```bash
npm run build
npm run preview
```

然后打开 http://localhost:8787。多人协议可用两个独立 WebSocket 客户端自动复测：

```bash
npm run test:multiplayer
```

## 部署

正式地址：<https://viz.gopromp.com>

正式环境使用 Cloudflare Workers Static Assets，配置文件为 `wrangler.jsonc`。运行 `npm run deploy` 会完成构建并更新正式站点。

同时保留 Cloudflare Pages 项目 `viz` 作为备用部署与预览地址；构建命令为 `npm run build`，输出目录为 `dist`。

## 关于内容的准确性

演示里出现的数值都是实时算出来的，不是写死的动画。做的时候用独立的 Node 脚本交叉验证过：

- 挂谷集的体积与 Perron 树递归的独立实现比对，相对误差 < 1e-5
- 12 个方向锥的覆盖率用 6 万个随机方向抽样验证：100%，且 12 个变换矩阵严格正交
- 硬球气体的能量守恒到 1e-8（机器精度）；速率分布与麦克斯韦–玻尔兹曼曲线的 L1 偏差落在 √N 散粒噪声量级内
- H 函数在时间反演后的回升幅度、盒维数随尺度的变化，都是实测数据
- 玻尔兹曼双轨实验从同一随机种子重建粒子位置与速度，并比较初态校验码；校验失败时不接受因果结论
- 意识文章中的三组预测、五件证物和判定范围逐项来自 2023 年预注册协议与 2025 年 Nature 最终报告；不把生物学实现的失败外推成对整套理论或机器意识的判决
- 布雷斯文章中的路线时间、均衡流量、22.5 分钟激励最优点与需求窗口均由同一组道路成本函数实时计算；动画只插值流量，不改写均衡结果
- 反应扩散文章固定使用 Dᵤ=1、Dᵥ=0.5、Δt=1 的显式 Euler 更新、3×3 离散拉普拉斯和环形边界；四组预设均用独立脚本运行 8000 步确认不会衰减为空场
- 引力波文章内嵌的官方 WAV 与 LIGO-G2501806-v4 文件 SHA-256 一致；啁啾时长和 ḟ 用独立实现核验，匹配实验固定噪声种子并显示注入真值与峰值误差
- 语言游戏用两个真实 WebSocket 客户端跑满 12 回合，验证自动配对、角色交替、接收者目标保密、越权消息拒绝、第三人拒绝、断线重连与匿名汇总只计一次
