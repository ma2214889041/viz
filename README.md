# viz

把复杂的东西做成能上手玩的可交互演示。数学、物理、数据、系统——什么有意思做什么。

每个作品都是**一个自包含的 HTML 文件**：没有构建步骤，没有外部依赖，没有 CDN。双击就能开，也能直接扔到任何静态托管上。

## 作品

| | 作品 | 说明 |
|---|---|---|
| 数学 | [一根针与一盒气体](kakeya-boltzmann/) | 三维挂谷猜想 + 希尔伯特第六问题。手写 WebGL，10 + 7 章分步讲解。 |

## 加一个新作品

1. 建文件夹 `your-work/`，放一个 `index.html` 进去
2. 在根目录 `index.html` 顶部的 `WORKS` 数组里加一条

```js
{ dir:'your-work', tag:'物理', color:'#ffd866',
  title:'标题', desc:'一句话说明' }
```

就这样。没有别的步骤。

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000

## 部署

纯静态站点，任何静态托管都行。Cloudflare Pages 连上这个仓库即可，构建命令留空、输出目录填 `/`。

## 关于内容的准确性

演示里出现的数值都是实时算出来的，不是写死的动画。做的时候用独立的 Node 脚本交叉验证过：

- 挂谷集的体积与 Perron 树递归的独立实现比对，相对误差 < 1e-5
- 12 个方向锥的覆盖率用 6 万个随机方向抽样验证：100%，且 12 个变换矩阵严格正交
- 硬球气体的能量守恒到 1e-8（机器精度）；速率分布与麦克斯韦–玻尔兹曼曲线的 L1 偏差落在 √N 散粒噪声量级内
- H 函数在时间反演后的回升幅度、盒维数随尺度的变化，都是实测数据
